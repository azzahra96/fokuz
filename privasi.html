Kebijakan Privasi

Contoh teks — ganti dengan kebijakan resmi bisnismu.

Data yang kami simpan

Nama, email, nomor telepon, isi brief, file yang kamu unggah, dan riwayat pesanan.

Penggunaan data

Data hanya dipakai untuk mengerjakan pesananmu dan menghubungimu terkait pesanan.

Keamanan file

File hanya dapat diakses oleh kamu dan tim Fokuz yang menangani pesanan. Tautan unduhan bersifat sementara.

Hak kamu

Kamu dapat meminta data dihapus melalui menu Bantuan.
